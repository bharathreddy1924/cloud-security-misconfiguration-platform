First-time Google Cloud Console setup instructions
  1. Go to the Google Cloud Console → Credentials.
  2. Configure the OAuth Consent Screen (User Type: External, scope: openid, email, profile).
  3. Create an OAuth 2.0 Client ID (Application type: Web application).
  4. Add Authorized JavaScript origins: http://localhost:3000 and http://localhost:3001
  5. Add Authorized redirect URIs: http://localhost:3000/auth/google/callback
    http://localhost:3001/auth/google/callback
  6. Copy your Client ID and Client Secret into your project's .env file.
